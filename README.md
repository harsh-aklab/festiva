# Festiva – Event Planning & Management Platform 🎉

**Plan smarter. Celebrate better.**

Festiva is an AI-assisted event planning and management web prototype designed to make event organization easier. It brings event planning, service discovery, budget estimation, decoration inspiration, and provider management together in one platform.

🌐 **Live Demo:** https://festiva-event-market-8cpy.bolt.host

## ✨ Features

- Event planning through a guided form.
- Event service marketplace with filters.
- Provider profiles and portfolios.
- Event recommendations based on user requirements.
- Decoration design studio.
- Event budget calculator.
- Quotation comparison.
- Booking workflow interface.
- Customer, provider, and admin dashboards.
- Messaging interface.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Bolt.new (AI-assisted development)

## 💻 Run Locally

Clone the repository:

```bash
git clone https://github.com/harsh-aklab/festiva.git
```

Navigate to the project:

```bash
cd festiva
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
